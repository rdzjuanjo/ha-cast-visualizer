# Changelog

## 0.1.1

- Squeezelite now uses a stable MAC derived from the player name, so several instances (or another
  squeezelite) on the same host no longer collide in Music Assistant. The player gets a new id: remove the old
  one from Music Assistant after updating.

## 0.1.0

- First public release: Music Assistant (Squeezelite) player, projectM in headless sway, x264 HLS to Chromecast,
  silence and "other app" watchers, visual control and lists, webhooks, Home Assistant package and blueprint.
